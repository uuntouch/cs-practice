# Git

## Рабочая папка

Рабочая папка — это состояние файлов проекта, с которыми я непосредственно работаю.

## Индекс

Индекс — это область, куда Git помещает изменения, подготовленные для следующего коммита.

## Коммит

Коммит — это сохранённая версия подготовленных изменений с сообщением и информацией об авторе.

## Git и GitHub

Git — это система контроля версий, которая работает локально и позволяет отслеживать изменения в проекте.

GitHub — это онлайн-сервис для хранения Git-репозиториев и совместной работы с ними.

Git может работать без GitHub, потому что история проекта хранится локально. GitHub используется как удалённый репозиторий, с которым можно обмениваться изменениями.

## Использованные команды

### git status

Показывает текущее состояние рабочей папки и индекса: какие файлы изменены, какие подготовлены к коммиту, а какие ещё не отслеживаются.

### git diff

Показывает изменения между рабочей папкой и индексом.

### git diff --staged

Показывает изменения, добавленные в индекс, относительно последнего коммита.

## Ветки

Ветка — это отдельная линия разработки, которая указывает на определённый коммит.

При создании нового коммита ветка перемещается и начинает указывать на этот новый коммит. Предыдущие коммиты при этом не изменяются.

Слияние объединяет изменения из одной ветки с другой. В результате изменения из выбранной ветки становятся частью истории текущей ветки.
