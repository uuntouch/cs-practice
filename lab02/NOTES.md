# Git

## Рабочая папка

Рабочая папка — это состояние файлов проекта, с которыми я непосредственно работаю.

## Индекс

Индекс — это область, куда Git помещает изменения, подготовленные для следующего коммита.

## Коммит

Коммит — это сохранённая версия подготовленных изменений с сообщением и информацией об авторе.

## Git и GitHub

Git — это система контроля версий, которая работает локально и позволяет отслеживать изменения в проекте.

GitHub — это онлайн-сервис для хранения Git-репозиториев и совместной работы с ними.

Git может работать без GitHub, потому что история проекта хранится локально. GitHub используется как удалённый репозиторий, с которым можно обмениваться изменениями.
